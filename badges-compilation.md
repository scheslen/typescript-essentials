## Reflections

[Add your personal reflections on what you learned in each module and how it contributes to your development skills]

01 - We learned that TypeScript is an open-source language and it's a superset of JavaScript.
The core feature of TypeScript is its type system. To transform TypeScript code into JavaScript,  
we need to install TypeScript compiler, which is called tsc.
We learned how to install TypeScript, set up a TypeScript project in Visual Studio Code,  
generate and configure a tsconfig.json file, compile TypeScript to JavaScript.

02 - The main benefit of TypeScript is that it enables to add static types to dynamically typed  
JavaScript code. The static type system also provide better documentation, and allow TypeScript  
to validate that code is working correctly. 
We have learned to declare variables using primitive and object types, union and intersection types,  
literal types, type assertion and type guards.

03 - We can use interfaces to describe an object, naming and parameterizing the object's types,  
and to compose existing named object types into new ones. The interface doesn't initialize or implement  
the properties declared within it.
We have learned to declare, instantiate and extend an interface.  

04 - We learned that adding types offers the benefit of type checking the values that we pass to  
the function and what is returned. As in JavaScript, we can define functions in TypeScript several  
different ways: named functions, anonymous and arrow functions. 
The TypeScript compiler assumes, by default, that all parameters defined in a function are required.  
But we can also define optional parameters, default, rest parameters and deconstructed object parameters.
We learned how to define function types using type aliases or interfaces.

05 - Classes in TypeScript extend the ES6 functionality by adding TypeScript-specific features like  
type annotations for class members, access modifiers, and the ability to specify required or optional  
parameters. We learned how to create a class and define its members: properties, a constructor,  
accessors, and methods.
We can use also an interface to ensure class instance shape. Class declarations may reference
one or more interfaces. 

06 - Generics are code templates that tell functions, classes, or interfaces what type we want to use  
when we call it. Generics can provide more flexibility when working with types, enable code reuse,  
reduce the need to use the any type. We can not only apply native types to generic type variables,  
but also interfaces, functions, and classes. 
We have learned to declare a generic interface as a function type, implement generic interface in a class,  
use generic constraints with custom types and classes.  

07 - Modules organize code, enabling to group related code together. Also, they help to avoid naming   
conflicts between components in the global namespace. Any file containing a top-level import or export  
statement is considered a module. We can export a variable, function, class, type alias, or interface.
We can use also external libraries in TypeScript code after importing them and their type definition.
We have learned how to organize code using modules and how import an external type library.  

08 - Namespaces allow to group variables, functions, interfaces, or classes related to business rules  
in one namespace and security in another. They provide a context for names, which helps reduce naming   
collisions and enhance reusability code. We can implement namespaces within a single file or across  
multiple TypeScript files. We can also nest namespaces within namespaces.  
We have learned how to organize code with namespaces.
